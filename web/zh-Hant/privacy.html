隱私權政策

最後更新日期：2026 年 11 月 1 日 「台灣空氣品質 Taiwan Air」（以下稱「本 App」，App Store ID 1286516443，Bundle ID com.kfpun.twaqi）在 iPhone、iPad、Apple Watch 與 Apple Vision Pro 上提供台灣各政府空氣品質監測站的觀測數值，由獨立開發者製作。我們將資料蒐集降到最低。本政策說明我們蒐集哪些資料、用途，以及會分享給誰。 重點摘要 • 不需要註冊帳號，您不必告訴我們您是誰也能使用本 App。 • 收藏的測站與各項設定都留在您的裝置上。 • 定位為選用，且只在您的裝置本機使用。 • 只有在您送出「意見回饋 / 聯絡我們」或「商業合作」表單時，我們才會收到您的姓名與電子郵件。 空氣品質資料來源 • 觀測數值為環境部（原行政院環境保護署）公開的開放資料，本 App 透過我們自建、架設於 Amazon Web Services 的 API 取得。 • 這些資料描述的是監測站，而非個人。向我們 API 發出的請求僅包含國家代碼、測站 ID 與筆數上限，不含帳號、裝置識別碼或座標。 • 空品區預報由我們的內容管理伺服器 cms.wahthefox.com（Directus）讀取；測站即時影像由 twaqi.app.wahthefox.com（Cloudflare）載入。這些請求都不含個人資料。 儲存在您裝置上的資料 • 本 App 不需要註冊帳號。 • 您的設定只留在裝置上：所選的指標（AQI、PM2.5 等）、收藏的測站、上次的地圖位置、勿擾時段、語言、最近一次判定的最近測站，以及是否已購買移除廣告。主畫面小工具與 Apple Watch App 會從您的裝置讀取相同設定。 • 空氣品質數值、預報與測站影像會暫存在裝置上供離線瀏覽，約一週後自動清除。 • 刪除本 App 即會一併移除這些裝置上的資料。唯一的例外是警示功能使用的隨機裝置 ID（請見「通知」）：它以「僅限此裝置」（ThisDeviceOnly）的存取設定保存在 iOS 鑰匙圈中，因此在同一台裝置上刪除並重新安裝本 App 後可能仍會保留；透過備份或回復移轉到新裝置時則不會帶過去。 「意見回饋 / 聯絡我們」與「商業合作」表單 • 這兩份表單是本 App 唯一會請您提供個人資料的地方，是否送出完全由您決定。您送出的內容會透過 HTTPS 傳送到我們的 Directus 內容管理系統（cms.wahthefox.com），並儲存於其中（資料集名稱為 twaqi_feedback 與 twaqi_cooperate）。 • 「意見回饋 / 聯絡我們」（位於「說明」頁面）會送出：您的電子郵件（必填，方便我們回覆）、名字（選填）、滿意度星等、建議內容、其他意見或問題（選填），以及您是否有興趣參加用戶訪談。 • 「商業合作」（「說明」›「想成為我們的合作夥伴嗎？」）會送出：合作類型、公司名稱、您的姓名、電子郵件、職稱（選填）、電話（選填）、網站（選填）與留言內容。 • 為協助我們查明問題，兩份表單也會一併送出技術資訊：App 版本與組建編號、App 的 Bundle ID、裝置型號與類型（例如 iPhone、iPad 或 Apple Vision Pro）、iOS 版本、語言與地區設定（含您偏好的前三種語言）、時區及平台。「意見回饋 / 聯絡我們」表單另會附上裝置的廠商識別碼（identifier for vendor；同一開發者在此裝置上的 App 共用，僅在移除我們全部 App 後才會重設），以便將同一台裝置的多次回報歸在一起；「商業合作」表單則不會送出。 • 這些資料只用於閱讀並回覆您的訊息、跟進合作洽詢、在您表示有興趣時邀請您參加用戶訪談，以及改善本 App。我們不會將您加入行銷名單，也不會販售這些資料。 定位 • 定位權限為選用，且僅在您使用本 App 時取用（「使用定位以選擇離您最近的空氣品質監測站」）。 • 您的座標只在裝置本機用於將地圖置中，以及計算距離您最近的監測站。座標不會傳送至我們的 API 或內容管理伺服器，我們也不會儲存。 • 地圖由 Google Maps SDK 繪製，Google 可能依其隱私權政策處理定位與裝置資料。 • 若您拒絕定位權限，本 App 仍可正常使用，會改用預設測站以及您在地圖上自行選擇的測站。 通知 • 推播通知由 OneSignal 傳送。當您為某測站開啟警示時，該測站、您設定的門檻值與勿擾時段會以標籤（tags）形式存放於 OneSignal 的推播紀錄中，以便送出通知。OneSignal 會取得推播 token 與一般裝置資訊。 • 相同的警示設定也會複製一份到我們的 Directus
