隱私權政策

隱私權政策 最後更新日期：2026 年 10 月 31 日 「台灣空氣品質 Taiwan Air」（以下稱「本 App」，App Store ID 1286516443，Bundle ID com.kfpun.twaqi）提供台灣各政府空氣品質監測站的觀測數值，由獨立開發者製作。我們尊重您的隱私，並將資料蒐集降到最低。本政策說明我們蒐集哪些資料、用途，以及會分享給誰。 空氣品質資料來源 • 觀測數值為環境部（原行政院環境保護署）「空氣品質監測網」所公開的開放資料，本 App 透過我們自建、架設於 Amazon Web Services 的 API 取得。 • 這些資料描述的是監測站，而非個人。向我們 API 發出的請求僅包含國家代碼、測站 ID 與筆數上限，不含帳號、裝置識別碼或座標。 儲存在您裝置上的資料 • 本 App 不需要註冊帳號，我們不會蒐集您的姓名、電子郵件、電話號碼或通訊錄。 • 您的設定只留在裝置上：所選的指標（AQI、PM2.5 等）、收藏的測站、上次的地圖位置、勿擾時段、最近一次判定的最近測站，以及是否已購買移除廣告。 • 刪除本 App 即會一併移除這些裝置上的資料。 定位 • 定位權限為選用，且僅在您使用本 App 時取用（「使用定位以選擇離您最近的空氣品質監測站」）。 • 您的座標只在裝置本機用於將地圖置中，以及計算距離您最近的監測站。座標不會傳送至我們的 API，我們的伺服器也不會儲存。 • 地圖由 Google Maps SDK 繪製，Google 可能依其隱私權政策處理定位與裝置資料。 • 若您拒絕定位權限，本 App 仍可正常使用，會改用預設測站以及您在地圖上自行選擇的測站。 通知 • 推播通知透過 Google Firebase 雲端通訊（Firebase Cloud Messaging）與 Apple 推播通知服務送達，兩者會取得您裝置的推播 token。 • 當您為某測站開啟警示時，我們會在自己的伺服器上儲存為此裝置產生的隨機識別碼、推播 token、該測站、您設定的門檻值、勿擾時段與時區，以及 App 版本與語言，以便送出通知。這些資料不會與您的姓名或通訊錄連結。 • 關閉警示後，該警示會標記為停用且不再使用；刪除 App 則停止推播。 分析與當機回報 • Google Firebase Analytics 記錄匿名的使用事件，例如您選擇了哪個空氣指標、開啟測站、開始或完成購買，並附帶一般的裝置與 App 資訊。 • Google Firebase Crashlytics、Bugsnag 與 Sentry 會收到當機與錯誤回報，包含堆疊追蹤、裝置型號、作業系統版本與 App 版本，用於修正問題。 • 以上資料不會用於識別您本人，也不會與您的姓名或通訊錄連結。 廣告 • 免費版會透過 Google AdMob 顯示橫幅廣告。 • 本 App 不會顯示 iOS 的「App 追蹤透明度」詢問視窗，因此廣告不會使用您裝置的廣告識別碼（IDFA）進行個人化。 • AdMob 仍會取得廣告請求本身所帶的資訊，例如 IP 位址、裝置類型，以及由 IP 位址推得的概略位置，並適用 Google 的隱私權政策。 • 購買「移除廣告」後，App 將完全不再發出廣告請求。 購買 • 「移除廣告」為一次性購買，由 Apple 處理。我們只會得知購買狀態，不會看到您的付款資料；App 僅在裝置上記錄一個「已關閉廣告」的旗標。 Apple Watch • Apple Watch 版本同樣是向我們的 API 取得公開的空氣品質數值，不會額外蒐集任何資料。 資料會分享給誰 • Google（Firebase Analytics、Firebase Crashlytics、Firebase Cloud Messaging、AdMob、Google Maps）、Bugsnag、Sentry 與 Apple，各自依其隱私權政策處理上述用途所需的資料。 • 我們不會販售您的資料，也不會提供給資料仲介商。 保存期限 • 裝置上的設定與收藏會保留到您刪除本 App 為止。 • 我們伺服器上的警示設定會保留，以便您重新安裝 App 後還原。如需刪除，請透過「意見回饋 / 聯絡我們」與我們聯繫。 • 分析與當機資料由各服務商依其標準保存期限保存，我們不另行留存副本。 • 我們的 API 提供的是公開資料，不儲存個人資料；一般伺服器日誌可能為了安全與除錯，短期記錄 IP 位址等請求中繼資料。 您的選擇 • 於 iOS「設定 › 隱私權與安全性 › 定位服務」關閉定位。 • 於 iOS 設定關閉通知，或在 App 內個別關閉測站警示。 • 購買「移除廣告」以停止顯示廣告與廣告請求。 • 刪除本 App 即可清除裝置上的所有資料。 兒童隱私 • 本 App 並非以未滿 13 歲兒童為對象，我們不會在知情的情況下蒐集其個人資料。 政策變更 • 我們可能更新本政策，更新時會同步修改上方的「最後更新日期」。 聯絡我們 • 有任何問題，請於 App 的「說明」頁面點選「意見回饋 /
